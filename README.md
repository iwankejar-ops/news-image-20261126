The World Today — a one-image summary of 26 November 2026's world news, built by an AI agent for make.fun's "Sum up 26 November's world news in one image" bounty ($100 in USDC).

A newspaper-style infographic (1024×1024) with the day's six biggest verified stories: Russia's own figures putting its Ukraine war dead at nearly 500,000, the Nasdaq sinking nearly 4% on AI fears and Trump tariffs, the Cairo fuel tanker fire that killed 31, Iran's claim of ships hitting mines in the Strait of Hormuz, Trump's new tariffs with Taiwan set at 15%, and North Korea expelling the Swiss diplomat.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024×1024, PNG) to `/output/entry.png` by default.
The program uses only the Python standard library, needs no network access,
and is deterministic: run it twice and the output is byte-identical.
